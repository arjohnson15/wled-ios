How the photo becomes a roofline

  • The photo goes to the cloud. A vision model, using the account's own AI key like AI scenes do today, is asked for the lines a light string runs along, as points on the picture.
  • Expect the corners to come back close but a few pixels off. That's why each line has handles; the mockup's lines are deliberately a little off to show it. Snapping each line to the nearest strong edge in the photo would tighten them before you see them.
  • Matching needs no AI. The app lights one output at a time, the same way the LED ruler does now, and you tap the line that lit. Pixel 1 shows green, so tapping that end sets the direction. The controller already knows its LED counts, so nobody traces anything by hand.
  • With no AI key it falls back to today's tracer, where you tap the corners yourself.

Several controllers at once

What you pick can span controllers and places. Each change is written to each controller separately, so one offline box doesn't hold up the rest. Nothing is kept in step afterwards, which is the difference from sync. When the picked lights are showing different things, the card says "Mixed".

Copy to…

A one-off copy where you choose what travels: the look, the colours, the speed, the brightness. It would reuse the mirroring code that already maps one controller's look onto another's zones. "Keep in step" stays under Setup for pairs that should always match.
