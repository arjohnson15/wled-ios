# JTS Lights for iPhone

The iPhone app for **JTS Lights**: permanent house lighting on WLED controllers, controlled
through the JTS cloud (`https://wled.cloudjohnson.com`).

**Status (2026-11-02): design only, no app code yet.** The design is agreed and documented
here so the first version can be built and tried in the iOS Simulator.

| Start here | |
|---|---|
| `AGENTS.md` | instructions and definition of done for whoever builds the first version |
| `docs/DESIGN.md` | the "Your house" design: every screen, state, token and decision |
| `mockups/your-house.html` | interactive mockup; open in Safari |
| `mockups/screens/` | stills of every screen, in flow order |
| `docs/API.md` | the cloud API the app uses (existing and proposed) |
| `docs/WLED-PRIMER.md` | controller behaviour the app must respect |
| `reference/` | mock account, looks catalogue, effect preview reference |
| `brand/` | logo, square and wide |

Related repos: firmware fork `arjohnson15/WLED` (branch `v16-house`). The cloud server is
private and not on GitHub.
